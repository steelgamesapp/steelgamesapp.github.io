How SteelGames helps you pay less for PC games

SteelGames is a veteran-owned site that shows the lowest current price for a PC game across official stores and trusted resellers, so you do not have to check each store by hand. Every game page lists the stores that carry it, the best price we can find, and the lowest price that game has ever sold for.

Is the sale real?

List prices can be inflated. Compare the current price with the game's price history before you buy.

Where should you buy?

Steam, Epic and GOG differ on refunds, DRM and free games. Our guide compares them.

Are cheap keys safe?

Learn the difference between authorized stores and key marketplaces, with a checklist.

Gear buying guides

Mice, keyboards, headsets, monitors and controllers, with advice on how to choose.

Buy now, or wait?

Each game page includes a Wait-O-Meter that scores from 0 (buy now) to 100 (wait). It looks at how far today's price sits above the game's all-time low, how soon the next big sale event is, and how often the game has dipped in price before. It is a guide, not a promise, because publishers can change prices at any time.
