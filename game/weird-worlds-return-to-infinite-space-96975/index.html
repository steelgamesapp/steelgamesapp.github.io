About Weird Worlds: Return to Infinite Space

Weird Worlds: Return to Infinite Space, from the small studio Digital Eel, is a roguelike about exploring space. Each game is a short expedition in a randomly generated part of the galaxy, where you pilot a starship, visit star systems, meet odd alien races, find artifacts and recruit allies, all while racing against a time limit before you must return home. Starship battles break out when encounters turn hostile.

A single game takes roughly half an hour, so it fits short sessions and shows something new each time. It is a single-player game with a light, quirky tone and simple controls. Weird Worlds suits players who like quick space adventures and the replay value of a roguelike.
