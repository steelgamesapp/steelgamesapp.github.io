Best budget keyboard

Redragon Fizz K617 60%

60% mechanical keyboard

At $44.99 (regular price $47.99), the Fizz K617 is a compact 61-key keyboard. Redragon lists red switches that are hot-swappable, so you can change switches later without soldering. The page says the cable is a detachable USB-C cable and lists up to 20 RGB backlight presets.

A 60% layout leaves out the arrow keys, function row and number pad as separate keys, which frees up desk space for your mouse. Redragon's page says it is software customizable.

Good: Small footprint; hot-swappable; the lowest keyboard price here.
Watch for: Wired only; no function row or arrow keys on their own, so some people need time to get used to it.

How to choose

Keyboard size. A 60% keyboard like the K617 saves space but drops dedicated arrows and function keys. A 75% like the HE80 keeps the arrows in a still-compact body.

Switch type. The K617 uses hot-swappable red switches, which are the common choice for smooth, light keypresses. The HE80 uses magnetic switches that let you set how far a key needs to move before it counts. This is aimed at shooters and other fast games.

Wired or wireless. A wired keyboard never needs charging. For a mouse, wireless is convenient, but check that the wired mode works too in case the battery runs low.

Questions

Is a 60% keyboard good for gaming?

Many players like the extra desk space for their mouse. You give up the arrow keys and function row as separate keys, which can matter in some games.

Do I need to use the software?

Both makers list software for changing lighting, buttons and macros, but you can use the products without it.

Are these prices permanent?

No. The stores showed sale prices on November 13, 2026 and they can change at any time.
